# Amazon Clone - HTML & CSS

This is a simple front-end clone of the Amazon homepage, built using **HTML** and **CSS**. It mimics the layout and design of Amazon’s landing page including the navbar, hero section, and product category boxes.

## 📁 Project Structure


## 🧰 Technologies Used

- HTML5
- CSS3
- Font Awesome (for icons)

## 🔧 Features

- Responsive layout using Flexbox
- Hover effects and transitions
- Fully styled navigation bar, search bar, and footer
- Hero image with promotional text
- Multiple product category boxes with images
